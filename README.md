# HR Analytics Dashboard

An end-to-end HR data analysis project built in Excel, covering data cleaning,
salary and performance analysis, and an interactive dashboard.

## 📁 Dataset
- **20,000** employee records
- **120** managers
- **10** cities with bonus rates
- Fields: Department, Designation, City, Salary, Attendance %, Performance Score, and more

## 🛠 Tools & Skills Used
- Excel Formulas: VLOOKUP, AVERAGEIF, CORREL, DATEDIF, IF, IFERROR
- Pivot Tables & Pivot Charts
- Data Cleaning & Validation
- Dashboard Design with Slicers & KPI Cards

## 🔍 Process
1. **Data Quality Checks** – identified and fixed duplicate IDs, missing values, and broken lookups
2. **Salary Analysis** – calculated total salary, compared departments against the company average
3. **Performance & Attendance Analysis** – classified employees, checked correlations
4. **Business Analysis** – studied department and city-level trends
5. **Dashboard** – built KPI cards, charts, and filters for interactive exploration

## 📊 Key Insights
- Average salary: ₹69,109 | Total salary cost: ₹138.22 Cr
- HR has the largest workforce and highest average pay
- Procurement has the highest average performance score
- Salary shows almost no correlation with performance (0.003)
- 1,721 employees flagged for attention (low attendance or performance)
